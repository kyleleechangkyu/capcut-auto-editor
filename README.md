# CapCut 자동 편집기

영상 하나를 넣으면 **컷 편집 + 자막**이 끝난 CapCut 초안이 만들어집니다.
완성본이 아니라 **초안**입니다 — CapCut에서 열어 손보고 내보내세요.

## 쓰는 법

**`CapCut 자동편집기.command` 를 더블클릭** → 브라우저 화면이 열립니다 → 영상을 끌어다 놓으면 끝.

처음 한 번은 설치가 돌아 몇 분 걸립니다. 그 다음부터는 바로 열립니다.
(첫 편집 때 음성 인식 모델 약 1.6GB를 한 번 내려받습니다)

## 자막 스타일

CapCut의 텍스트 템플릿·말풍선·애니메이션은 코드로 만들 수 없어서,
**직접 고른 것을 그대로 복제**하는 방식을 씁니다.

1. CapCut에서 자막 한 줄을 원하는 스타일로 만들어 프로젝트를 저장합니다
2. 앱 화면의 **자막 스타일** 목록에서 그 프로젝트를 고릅니다
3. 무엇을 읽어냈는지 (말풍선·텍스트 효과·템플릿·애니메이션) 바로 아래에 표시됩니다

스타일을 바꾸고 싶으면 CapCut에서 그 프로젝트만 고치면 됩니다.
고르지 않으면 흰 글씨 + 검은 테두리의 기본 자막이 됩니다.

## 편집 결과 확인

편집이 끝나면 화면에 **타임라인 막대**가 나옵니다. 파란색이 남긴 부분,
회색·노랑·빨강이 각각 무음·말더듬·재촬영으로 잘라낸 부분입니다.
마우스를 올리면 구간과 사유가 보입니다.

컷이 과하거나 모자라면 **컷 세기**를 바꿔 다시 돌리세요.
같은 영상을 다시 돌릴 때는 음성 인식을 건너뛰어 몇 초면 끝납니다.

## 알아둘 것

- 드래그해서 넣은 영상은 앱 폴더의 `media/` 에 보관됩니다. **여기 파일을 옮기거나 지우면**
  CapCut에서 "미디어를 찾을 수 없음"이 뜹니다.
  (`파일 선택` 버튼으로 고르면 복사하지 않고 원래 자리의 파일을 그대로 씁니다)
- 새 초안은 **CapCut을 껐다 켜야** 목록에 나타납니다.
- 결과 파일은 `work/<영상이름>/` 에 리포트(report.md), 자막(.srt), 원본 데이터(cuts.json)로 남습니다.

## 폴더 구조

```
CapCut 자동편집기.command   ← 이것만 더블클릭
app/server.py              로컬 앱 서버
app/ui.html                화면
agent/audio.py             ffmpeg — 오디오 추출, 무음 감지
agent/transcribe.py        음성 인식 (faster-whisper) + 캐시
agent/detect.py            컷 판정 + 타임라인 재계산
agent/subtitles.py         자막 줄 나누기 + SRT
agent/draft.py             CapCut 초안 쓰기 + 스타일 복제
agent/defaults.py          기본값
settings.json              화면에서 바꾼 설정 (자동 생성)
media/                     넣은 영상 보관
work/                      리포트·자막·중간 결과
```
